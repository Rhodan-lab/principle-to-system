# Investigations

Investigations turn observation into evidence without copying the structure of school laboratory worksheets. They begin with a question that can produce more than one reasonable model.

## Investigation cycle

```text
question
→ competing explanations
→ measurable quantities
→ safe observation plan
→ uncertainty record
→ model comparison
→ revised explanation
→ transfer to another system
```

## Evidence rules

- Never present one noisy observation as proof.
- Record conditions that may alter the result.
- Distinguish measurement resolution from natural variation.
- Preserve inconvenient observations rather than deleting them.
- Prefer plots, rates, ratios, and uncertainty ranges over isolated numbers.
- A result that contradicts the initial idea is still a successful investigation.
