# Investigations

Investigations turn observations into evidence without pretending that one dataset proves a complete explanation. Each investigation compares at least two models, records uncertainty and disturbances, and ends by revising the explanation.

## Required structure

1. Question
2. Why the answer is not obvious
3. Competing models
4. Variables and units
5. Safe observation or simulation method
6. Data-recording structure
7. Uncertainty and confounders
8. Analysis method
9. Interpretation limits
10. Model revision
11. Transfer questions
12. Sources and module links
